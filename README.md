# Studio Carte NFC

Site test de création de cartes de visite numériques pour cartes NFC.
Secteur → modèle → couleurs → contenu → publication (lien + QR code).

- Bilingue français / anglais (site et carte)
- 20 secteurs, 10 modèles, 5 palettes par secteur
- Responsive : ordinateur, tablette et téléphone

Site statique : HTML, CSS et JavaScript, sans dépendance à installer.
